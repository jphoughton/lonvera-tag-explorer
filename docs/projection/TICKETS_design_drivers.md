# Design tickets: Spend plan (drivers.js)

Page JS owner: proj-drivers. Details and screenshots: `DESIGN_REVIEW.md`.

1. **Bulk "Apply to N months" has no Undo (high).** After Apply the grid Undo button stays disabled and the only feedback is a 3-second toast ("Saved 36 changes to Marketing spend"). A wrong range fill overwrites up to 38 cells and the only way back is History, restore. Change: pass an Undo action in the toast (new in `ctx.toast`: `toast(msg, {kind:'ok', action:{label:'Undo', onClick: () => saveSeries(previousValues)}})`, stays 9 seconds) and push the previous values onto the grid undo stack (`grid` has `undoStack`; or call `grid.undo()` equivalent for a batch). Done when: apply, press Ctrl+Z or the toast Undo, and the 36 cells are back in one step.
2. **The copy cue shows the slug (medium).** "Editing a copy of current." should read "Editing a copy of Current plan." (use the base scenario's name from `ctx.scenarioInfo.base_slug` through the scenario list, not the slug).
3. **Compare is far from where you need it (medium).** "Compare scenarios" is the last block, below a 40-month grid and the plan settings. After cloning, nothing points to it. The shell now shows each headline number's difference from the plan of record in a copy, which covers the quick answer; for the full table add a "Compare with Current plan" button to the copy cue that scrolls to the section with the base scenario already picked (or move the section above "Plan settings").
4. **Compare table wording (low).** The rows read "Bull (this one) / Current plan / Difference vs Bull". The difference row is Current plan minus Bull, so it reads backwards when you are in Bull. Label it "Current plan compared with Bull" and show the sign from the viewing scenario's side.
5. **Chart slots (low).** The chart draws marketing spend in slot 1 (burnt orange), which is Vital Bull's colour everywhere else in the product. Use the ink "main" series for the series the page is about and slots 4 to 6 for non-product series (DESIGN.md section 11).

# Creative: rules for writing and grading Lonvera ad scripts

These files are copies of Josh's script-writing rules, so any agent can find them through the lonvera-brain `search` tool.

- `lonvera-brief-prep.md`: the evidence pass required before any brief, concept, script or hook list (skill `lonvera-brief-prep`).
- `script-voice.md`: how Lonvera scripts sound (voice, one-listen clarity, bridge for a cold viewer).
- `script-grader-brief.md`: the grader brief with the scoring rubric checks every script is scored against.
- `script-sell-harder.md`: the sell-harder rewrite guidance.

Each file starts with its source path and copy date. The sources are the truth; refresh with `scripts/sync_creative_skill.sh`, then commit and deploy `web`.
